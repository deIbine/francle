# Francle (Java)

## Francle et francle-web sont deux projets séparés

Depuis le 23 octobre 2026, ce dépôt et [deIbine/francle-web](https://github.com/deIbine/francle-web) sont
**indépendants**. La version web n'est plus qu'un **outil de comparaison** : on peut la lire (son code, son
historique, le jeu en ligne) pour comparer les deux versions ou s'en inspirer, rien de plus.

- **Pas de lien de travail** : pas de renvoi au plan ou aux documents du web, pas de tâche commune aux deux dépôts,
  pas de PR jumelle, pas de « à faire aussi côté web ». Ce qui concerne ce dépôt est écrit ici, dans
  `docs/feuille-de-route.md` et `docs/lecons.md`.
- **Une idée venue du web** est décidée, découpée et notée ici comme une idée du Java, sans attendre le web ni
  l'engager à quoi que ce soit.
- **Ce qu'on garde** : l'histoire (la phase 7 a donné naissance au web ; certaines phases ont repris ses
  nouveautés) et les comparaisons (« comme sur le web », écarts voulus entre les deux versions). L'adresse du jeu en
  ligne reste dans le partage et l'aide : c'est une fonction du jeu, pas un lien entre projets.
- **Ne jamais modifier** le dépôt francle-web depuis une conversation de ce projet.
